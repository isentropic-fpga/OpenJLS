    11:   -- has no clamp; the RTL clamps at 0. That clamp is provably a no-op for any 
    12:   -- T.87-coherent input, so the reference is the pure (unclamped) C formula and 
    13:   -- the check covers its full valid domain. 
    14:   -- 
    15:   -- Proof that EMErrval >= 0 for coherent inputs (so EMErrval<0 is unreachable): 
    16:   --   EMErrval<0 needs |Errval|=0 AND RItype+map>=1. But 
    17:   --     (1) a run-interruption sample is the breaking sample, so Ix/=Ra; with 
    18:   --         RItype=1 (A.17: Ra=Rb) A.18 gives Px=Ra and Errval=Ix-Ra/=0, and A.19 
    19:   --         ModRange keeps it nonzero -> RItype=1 implies |Errval|>=1; and 
    20:   --     (2) A.21 forces map=0 whenever Errval=0 (every map=1 clause needs Errval/=0). 
    21:   --   So |Errval|=0 with RItype+map>=1 cannot occur; EMErrval>=0 always, with =0 
    22:   --   reachable only at (RItype=0, map=0, Errval=0) -- which is driven and checked. 
    23:   -- Skipped (EMErrval<0) vectors are asserted to be exactly that forbidden combo.
