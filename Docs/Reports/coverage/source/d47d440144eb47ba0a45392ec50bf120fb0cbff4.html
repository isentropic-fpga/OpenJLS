    14:   -- every emitted bit (oRawSuffixVal, oRawSuffixLen MSB-first) into a bit string,

    17:   -- is validated implicitly: the reference tracks RUNindex with the C model and the 
    18:   -- next run's bits depend on it. Coverage: terminal type, immediate break,
